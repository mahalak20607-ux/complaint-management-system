# Complaint Management System

A professional web-based **Complaint Management System** designed to help users submit complaints, track complaint status, and allow administrators and staff to efficiently manage and resolve complaints.

## 🚀 Features

### User

* User registration and login
* User dashboard
* Submit complaints
* View submitted complaints
* Track complaint status
* View complaint details
* Update profile

### Admin

* Secure admin login
* Admin dashboard
* View and manage complaints
* Manage staff
* Assign complaints to staff
* Update complaint details
* View reports

### Staff

* Staff login
* Staff dashboard
* View assigned complaints
* Update complaint status
* Manage assigned complaints
* View complaint details

## 🔄 System Workflow

```text
User
  ↓
Register / Login
  ↓
User Dashboard
  ↓
Submit Complaint
  ↓
Admin Reviews Complaint
  ↓
Complaint Assigned to Staff
  ↓
Staff Updates Complaint
  ↓
Admin Monitors Progress
  ↓
Complaint Resolved
```

## 🎯 Objective

The main objective of this project is to provide a simple, organized, and user-friendly platform for managing public complaints digitally. It reduces manual work and makes complaint tracking easier for users, administrators, and staff.

## 💻 How to Run

1. Download or clone the project.
2. Open the project folder in **VS Code**.
3. Make sure all HTML, CSS, and JavaScript files are in their correct folders.
4. Open `index.html` using a browser or **Live Server**.
5. Navigate through the login and dashboard pages.
